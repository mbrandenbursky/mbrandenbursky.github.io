# Michael Brandenbursky — local-only academic homepage

Prepared 21 October 2026 for the repository mbrandenbursky/mbrandenbursky.github.io.

## Upload this complete package

This edition replaces the previous website packages. Upload ALL of its contents,
not only index.html: it adds the four supplied PDFs and updates the CV and old aliases.

1. Extract the ZIP into a NEW folder on your computer. Do not merge it with an old download.
2. Open the repository mbrandenbursky/mbrandenbursky.github.io on GitHub.
3. Select Code, then Add file > Upload files.
4. Drag ALL files from inside the extracted folder onto the upload page.
   Do not upload the ZIP itself or the enclosing folder. index.html must be at the
   top level of the repository, beside the PDFs. Keep every filename unchanged.
5. Enter a commit message such as "Install complete local-only homepage".
   Select Commit directly to the main branch, then Commit changes.
   Existing files with the same paths are replaced; the new PDFs are added.
6. If Pages is already enabled for main and /(root), keep those settings.
   Otherwise select Settings > Pages > Build and deployment > Deploy from a branch,
   then main and /(root), and Save.
7. Wait for the Pages deployment to succeed, then reload mbrandenbursky.github.io.
   On Windows, Ctrl+F5 reloads without using the usual page cache.

Keep the included .nojekyll file. It is an empty file, not a folder.
The package has fewer than 100 files and each file is smaller than 25 MiB.
No command line, package installation, build, paid service or external font is needed.

## Offline preview

After extracting, double-click index.html. The photograph, background, paper links
and CV work using the included files. The background is embedded in the HTML.
The webpage has no remote hyperlinks or resources. arXiv identifiers remain visible
and clickable, but open the corresponding LOCAL manuscript, not an arXiv record.
